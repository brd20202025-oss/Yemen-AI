# Yemen AI — Android offline-first starter

واجهة عربية لتطبيق أندرويد باسم Yemen AI، مع شاشة ترحيب، زر بدء المحادثة، زر «تعلّم من السحابة»، ذاكرة SQLite قابلة للإدارة، وبناء عبر GitHub Actions.

## ما يفعله زر «تعلّم من السحابة»؟

- يطلب موضوعًا ورمز Hugging Face من المستخدم.
- يرسل طلبًا إلى Hugging Face Inference Providers لتوليد مجموعة أمثلة سؤال/جواب باللغة العربية.
- يحفظ الأمثلة محليًا في SQLite.
- عند انقطاع الإنترنت، يحاول محرك النسخة المحلية مطابقة السؤال مع الأمثلة المحفوظة.

**هذا ليس تدريبًا لأوزان النموذج ولا ينقل النموذج السحابي إلى الهاتف.** إنه يحفظ معرفة نصية (Q&A cache) ويسترجعها بالمطابقة التقريبية. فهم الأسئلة الجديدة بشكل عام دون إنترنت يتطلب دمج نموذج لغوي محلي متوافق مع Android.

## المجانية والرمز

يتطلب التعلم السحابي اتصالًا بالإنترنت ورمز Hugging Face لديه صلاحية Inference Providers. الرصيد المجاني محدود وقد تتغير شروطه؛ لا يوجد ضمان لاستخدام غير محدود ومجاني. راجع الأسعار الرسمية: https://huggingface.co/docs/inference-providers/pricing

لا تضع الرمز في مستودع GitHub أو في الكود. في هذه النسخة يُدخل الرمز عند طلب التعلم ولا يُحفظ في قاعدة بيانات التطبيق، لكن يبقى استخدامه على جهازك مسؤوليتك. استخدم رمزًا محدود الصلاحيات ولا تشاركه.

## البناء عبر GitHub Actions

1. ارفع الملفات مع الحفاظ على المسار `.github/workflows/build.yml`.
2. افتح **Actions** وشغّل `Build Smart AI Android APK`.
3. إذا نجح البناء، نزّل `SmartAI-debug-APK` من قسم Artifacts.
4. إذا فشل، افتح سجل البناء. لا تعتبر APK جاهزًا حتى تنجح العملية.

## ميزات النسخة الحالية

- شاشة ترحيب باسم Yemen AI وزر «ابدأ المحادثة».
- زر «تعلّم من السحابة».
- سجل المحادثة محلي.
- إضافة/تعديل/حذف معلومات الذاكرة.
- حفظ أمثلة سؤال/جواب التي ينتجها النموذج السحابي.
- البحث التقريبي في الأمثلة المحفوظة عند العمل دون إنترنت.
- حقوق الواجهة: «برمجة وتوجيه عبدالحق يحيى الغولي — جميع الحقوق محفوظة».

## حدود معروفة

- لا يوجد نموذج لغوي محلي مدمج حتى الآن.
- المطابقة التقريبية ليست فهمًا دلاليًا كاملًا، وقد تفشل مع إعادة صياغة السؤال.
- خدمة السحابة ونموذج Qwen المحدد قد يغيران التوفر أو الحصة أو المعرف؛ عند الفشل تظهر رسالة خطأ.
- لا يمكن تأكيد بناء APK حتى ينتهي GitHub Actions بنجاح.
